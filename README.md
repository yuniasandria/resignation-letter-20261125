A one-line resignation letter from a cron job that only runs on 29 February, entered in the [make.fun competition](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

`main.py` (pure Python stdlib) writes the single line to `/output/entry.txt`:

> I work one day every four years and you still paged me on the other 1,460, so I am taking the next leap year off too.

117 characters, one line.
